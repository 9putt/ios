# iOS Foundation & UI Architecture Lab

A modular Swift laboratory exploring modern iOS SwiftUI layout patterns, custom gesture controllers, responsive multi-pane viewport stacking, and background execution architectures on iOS 16+.

## 🛠️ Project Scope

This repository provides clean architectural references and design pattern demonstrations:
- **Custom Viewport Hierarchies:** Exploring nested view stacking and responsive dynamic sheet behaviors.
- **Parametric DSP & Curve Visualizations:** Low-overhead vector rendering and real-time spline graphs using SwiftUI Canvas.
- **Lifecycle & State Synchronization:** Decoupled Combine publishers and persistent session management.
- **Accessibility & Tactile Feedback:** Custom slider mechanics with haptic engine integration.

## 📱 Requirements

- iOS 16.4 or later
- Xcode 15.0 or later
- Swift 5.0+
